For the a1 == 2 sub server mode

  • Parse the port number passed in a2
  • If 5555 then start byte matrix service at sub_140001687
  • If 6666 then start arithmetic operation service sub_140001A42
  • If 7777 then start comparison operation service sub_140001E45
  • Otherwise, return an error

Logic of sub services

  1. sub_140001687 (Comparison Operation Service)

    • Port: 5555

    • Receive: "<a> <b> <op_code>"

    • Remark: opcode only accept "<", ">", "="

    • Return: the boolean of comparison

  2. sub_140001A42 (Arithmetic Operation Service)

    • Port: 6666
    • Receive: "<a> <b> <op_code>"
    • Remark: opcode only accept "+", "-", "^"
    • Return: the result of arithmetic operation

  3. sub_140001687 (Byte Matrix Service)

    • Port: 5555
    • Receive: "<x> <y>"
    • Remark: which x and y are integer coordinate
    • Return: byte_140010020[28 * x + y]

def transform_matrix(data_bytes):
    matrix = [[0] * 28 for _ in range(28)]
    for k in range(28):
        for m in range(28):
            val = data_bytes[28 * k + m]
            matrix[k][m] = (val ^ 66) + 15
    return matrix

def print_matrix_as_ascii(matrix):
    for row in matrix:
        line = ''.join(chr(x) if 32 <= x <= 126 else '.' for x in row)
        print(line)
